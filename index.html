关于 MLearn

MLearn 是一个轻量、纯前端的机器学习自学平台，目标是把 Python 编程能力与机器学习核心知识 自然地结合在一起。所有内容在浏览器本地运行，无需后端，方便随时打开复习。

🎯 设计目标

  • 清晰的信息架构：首页 → 知识点 → 实践 → 问答。
  • 响应式体验：桌面端多栏、移动端抽屉与单列布局。
  • 即时反馈：搜索、问答、进度保存都在前端完成。

🧩 技术说明

  • 纯静态 HTML / CSS / JavaScript，无构建步骤。
  • 知识点与问答数据集中在 data.js。
  • 问答采用关键词匹配算法，可离线使用。

📈 使用建议

  • 先看「学习路径」建立全局认知。
  • 遇到不懂的概念，直接在「智能问答」里问。
  • 动手跑一遍「Python 实践」中的代码。

提示：本网站用于学习入门与复习。代码示例以 scikit-learn 为主，运行前请确保已安装 numpy、pandas、matplotlib、scikit-learn。
